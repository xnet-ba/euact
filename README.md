# eu-ai-act-article-4 — OpenCode Skill

Enforces **EU AI Act Article 4 (AI literacy)** + Recital 20, Regulation (EU) 2024/1689.
Applicable since 2 Feb 2025 to ALL providers/deployers of AI systems.

## Install

Copy to your project:
```
.opencode/skills/eu-ai-act-article-4/SKILL.md
```
Or global: `~/.config/opencode/skills/eu-ai-act-article-4/SKILL.md`

## What it does
- Forces role-based literacy: dev / deployer / user / affected person
- Covers Recital 20 four pillars: DEV, USE, OUTPUT, IMPACT
- Requires risk + safeguards disclosure, Art. 5 / Annex III triage
- Blocks prohibited practices, adds high-risk warnings
- Adds concise AI Literacy Notice template to AI outputs
- Never certifies compliance — points to EUR-Lex + Commission Art. 62(3)(b) examples
